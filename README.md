# Workplace Safety & HSE Analytics Dashboard

## Overview

This project presents an interactive Power BI dashboard developed using OSHA workplace incident data to analyze workplace safety trends, injury severity, environmental risk factors, and human contributing factors. The dashboard enables data-driven decision-making through KPI tracking and executive-level visualizations.

## Tools Used

- Microsoft Power BI
- DAX
- Power Query
- Microsoft Excel

## Dashboard Pages

### Executive Overview
Provides a high-level summary of total incidents, fatal incidents, nonfatal incidents, fatality rate, and overall incident trends.

### Incident Analysis
Analyzes incident types, injury categories, affected body parts, environmental factors, and human contributing factors.

### Risk Patterns & Severity Analysis
Examines relationships between incident severity, environmental conditions, and human factors to identify operational risks.

### Strategic Insights & Recommendations
Summarizes key findings and provides actionable recommendations to improve workplace safety performance.

## Key KPIs

- Total Incidents
- Fatal Incidents
- Nonfatal Incidents
- Fatality Rate

## Key Insights

- Falls from elevation are the leading workplace incident type.
- Struck-by and caught-in incidents remain significant contributors.
- Head and finger injuries account for a substantial proportion of cases.
- Human error and unsafe practices continue to influence workplace incidents.
- Material handling and work-surface conditions are major environmental risk factors.
